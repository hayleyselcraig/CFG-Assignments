# Assignment 4 | Ellie’s Dog Care Tracker API

A Python Flask API connected to a MySQL database that stores daily dog care activities such as walks, feeding, grooming, and vet visits.

## Technologies Used

- Python
- Flask
- Requests
- MySQL

## Project Files

- app.py
- main.py
- db_utils.py
- config.py
- dog_tracker.sql

## Features

- View all activities
- View one activity
- Add a new activity
